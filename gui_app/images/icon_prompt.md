# EventHorizon Icon Prompt

If you are recreating or refining the icon in Illustrator, here is the exact prompt that was used to generate the original concept image (`original_concept_icon.jpg`):

> A sleek, modern macOS app icon squircle. It features a minimalist, purely white and clear daily calendar icon—NO red colors anywhere on the calendar. The calendar header is clear/white. The calendar is being subtly warped, stretched, and pulled into a glowing cosmic singularity or dark void at the bottom right corner. Instead of numbers, the center of the calendar prominently displays the bold, clear letters "EH" in a clean sans-serif font. Deep space purples, blues, and neon highlights in the background. Minimalist, professional software logo design.
